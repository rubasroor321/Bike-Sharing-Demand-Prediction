# Bike Sharing Demand Prediction

This project focuses on predicting bike-sharing demand using
machine learning techniques, specifically Gradient Boosted Tree Ensembles.

## Files
- bike_sharing.ipynb: Jupyter Notebook with the full implementation
- report.pdf: Project report explaining methodology and results

## Tools
- Python
- Scikit-learn
- Pandas
- Jupyter Notebook
